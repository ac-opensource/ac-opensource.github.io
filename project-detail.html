AI Ops Prompt Engineering Team Process

Operations diary from running a Codex fleet: how we tuned prompts, instrumentation, and workflows to keep multi-agent delivery shippable.

01. CONTEXT

Where the fleet broke

We needed a stable agent loop for planning, implementation, testing, and review without wasting cycles. The hard part was keeping roles aligned while token usage and command repetition exploded.

CHALLENGE
  • 01

    Planner churn kept re-writing goals mid-iteration.

  • 02

    Implementer passes were re-running the same lint/test commands without sharing results.

  • 03

    Compose Multiplatform feedback loops were far slower than the same workflow on React web.

02. ARCHITECTURE

Prompt Surgery & Instrumentation

We froze the roadmap, tightened role expectations, and added run summaries. Once each role had explicit checklists and token visibility, iteration quality improved immediately.

orchestrator.config.ts 
// Freeze goals to stop planner thrash
const roadmapMode = "frozen";

// Force implementer to report exact commands + exits
requireSummaries({
  commands: ["make lint", "make test"],
  includeExitCodes: true,
});

// Parse role logs and surface token outliers
const stats = summarizeLogs(roleRuns);
alertIf(stats.implementer.maxTokens > 400000);
